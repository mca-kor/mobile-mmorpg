# 첫 시제품: 3인칭 이동

최종 갱신: 2026-10-29 (한국 시간)
상태: Mac·iPhone 시제품 정상 작동 사용자 보고 및 PR #6 병합 확인. 자동 테스트와 개별 검증 항목은 별도 확인 필요.

## 목표와 범위

작은 평지와 간단한 고정 장애물에서 캡슐 모양 캐릭터 1개를 움직인다. Mac의 WASD 이동, 바닥·장애물 충돌, 캐릭터 뒤·위에서 따라가는 3인칭 카메라를 먼저 구현한다.

오른쪽 마우스 버튼을 누른 채 움직이면 카메라가 좌우·상하 회전한다. 버튼을 놓으면 마우스 이동만으로 회전하지 않는다. 위아래 회전은 뒤집히지 않도록 제한한다.

첫 구현 기본값으로 카메라의 수평 방향을 기준으로 이동하고 캐릭터는 이동 방향을 바라본다. 시점만 돌릴 때 이동을 강제하지 않는다. 속도·감도·카메라 거리·회전 제한 각도는 실제 조작 후 조정하며 현재 수치를 확정하지 않는다.

## 단계

1. Mac 편집기에서 이동·충돌·카메라를 구현하고 검증한다.
2. Mac 정상 작동 사용자 보고와 PR #5 병합 후 iPhone을 첫 모바일 기기로 선택했다. 왼쪽 화면 조이스틱·오른쪽 드래그 시점·두 손가락 동시 조작을 구현했으며 Mac·iPhone 정상 작동 사용자 보고 후 PR #6이 병합됐다. 미확인 항목은 [iPhone 안내](IPHONE.md)에 따라 검증한다.

Mac 첫 단계에는 점프·달리기·전투·인벤토리·멀티플레이·로그인·서버·모바일 빌드를 포함하지 않았다. 이번 후속 단계는 iPhone 입력과 실기기 빌드 준비까지 확장한다. 점프·전투·서버는 계속 범위 밖이다. 카메라 벽 가림 해결과 줌은 후속 검토다. 첫 검증 맵은 카메라가 벽 안으로 들어가는 배치를 피한다.

## 완료 기준

아래 목록은 개별 확인할 항목이다. 정상 작동 사용자 보고만으로 모든 항목을 통과 처리하지 않는다.

- [ ] Play를 누르면 평지와 캐릭터가 보인다.
- [ ] WASD로 이동하고 키를 놓으면 멈춘다.
- [ ] 대각선 이동이 직선보다 빠르지 않다.
- [ ] 바닥과 고정 장애물을 통과하지 않는다.
- [ ] 이동 중 카메라가 캐릭터를 따라간다.
- [ ] 오른쪽 버튼을 누른 동안만 마우스로 시점이 회전한다.
- [ ] 상하 회전 중 카메라가 뒤집히지 않는다.
- [ ] 시점 회전 후 WASD가 카메라 수평 방향에 맞게 작동한다.
- [ ] 조작 종료 후 마우스로 Unity 메뉴를 사용할 수 있다.
- [ ] Window → General → Console에 새 빨간 오류가 없다.

## 구현 시 참고

Unity 6.3 LTS `6000.3.27f1`, `MobileMMORPG/`를 사용한다. 기존 SampleScene은 보존하고 별도 시제품 씬을 만든다. 필요한 .meta를 함께 기록한다. 구현·실행 결과와 미검증 항목은 [STATUS](STATUS.md)에 남긴다.

사용자가 3인칭 시점과 오른쪽 버튼 회전에 동의한 것을 근거로 작성했다. 메뉴·버튼은 화면 원문 그대로 표기한다. 첫 구현은 별도 작업 브랜치에서 준비한다. [실행·검증 안내](PLAYTEST.md)를 따라 Mac에서 확인한 뒤 검증 결과를 기록한다.
