# 주요 의사결정

확정된 결정과 검토 중인 제안을 구분한다. 확정할 때 날짜, 이유와 영향을 기록한다. 기존 결정을 바꿀 때는 이전 기록을 지우지 않고 새 결정으로 연결한다.

## 미정 사항

- Unity 6의 정확한 버전, 렌더링 방식, Unity 프로젝트 폴더 위치
- Android·iOS 우선순위와 최소 지원 기기
- 핵심 게임 경험, 첫 시제품 범위
- 서버 기술, 네트워크 구조, 데이터베이스와 호스팅
- 대형 아트 파일의 Git LFS 사용 범위·용량·비용

SETUP의 브랜치·PR 흐름은 초기 운영 가이드다. 향후 변경하면 이 문서에 기록한다.
