## Unity 프로젝트 확정 기록

2026-10-28 (한국 시간), [PR #2](https://github.com/mca-kor/mobile-mmorpg/pull/2) 병합과 사용자 보고를 근거로 기록한다.

- D-007: Unity 6.3 LTS `6000.3.27f1` 사용. 생성된 프로젝트의 버전 파일과 일치하며, D-001의 미정 버전을 확정한다.
- D-008: Universal 3D(URP), 프로젝트 경로 `MobileMMORPG/` 사용. 문서와 Unity 파일을 구분하고 기존 템플릿을 유지한다.
- 버전 업그레이드나 경로 변경은 별도 결정 후 진행한다.

## 첫 시제품 확정 기록

2026-10-28, 사용자의 3인칭 선택과 오른쪽 버튼 회전 동의를 근거로 기록한다.

- D-009: 작은 맵의 캡슐 캐릭터 이동·충돌·3인칭 따라가기 카메라. Mac의 WASD부터 검증하고 모바일 입력은 후속 단계로 나눈다.
- D-010: 오른쪽 마우스 버튼을 누른 채 움직이면 시점이 회전한다. 버튼을 놓으면 회전을 멈춘다.
- 범위·완료 기준과 조정 가능한 초기 기본값: [첫 시제품 기획](PROTOTYPE.md).
