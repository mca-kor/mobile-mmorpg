## Unity 프로젝트 확정 기록

2026-10-28 (한국 시간), [PR #2](https://github.com/mca-kor/mobile-mmorpg/pull/2) 병합과 사용자 보고를 근거로 기록한다.

- D-007: Unity 6.3 LTS `6000.3.27f1` 사용. 생성된 프로젝트의 버전 파일과 일치하며, D-001의 미정 버전을 확정한다.
- D-008: Universal 3D(URP), 프로젝트 경로 `MobileMMORPG/` 사용. 문서와 Unity 파일을 구분하고 기존 템플릿을 유지한다.
- 버전 업그레이드나 경로 변경은 별도 결정 후 진행한다.

## 첫 시제품 확정 기록

2026-10-28, 사용자의 3인칭 선택과 오른쪽 버튼 회전 동의를 근거로 기록한다.

- D-009: 작은 맵의 캡슐 캐릭터 이동·충돌·3인칭 따라가기 카메라. Mac의 WASD부터 검증하고 모바일 입력은 후속 단계로 나눈다.
- D-010: 오른쪽 마우스 버튼을 누른 채 움직이면 시점이 회전한다. 버튼을 놓으면 회전을 멈춘다.
- 범위·완료 기준과 조정 가능한 초기 기본값: [첫 시제품 기획](PROTOTYPE.md).

## 첫 시제품 구현 방식

2026-10-28, 첫 시제품 구현 요청에 따라 다음 기술 방식을 사용한다. 추후 변경 가능하다.

- D-011: 기존 Input System과 CharacterController로 이동·충돌·중력을 구현한다. 새 패키지는 추가하지 않는다.
- D-012: 기존 SampleScene을 보존하고 `Assets/Prototype/Scenes/ThirdPersonPrototype.unity`를 사용한다. Play 시 전용 컴포넌트가 임시 맵·캐릭터·카메라·조명을 생성한다. 편집 중 오브젝트 수동 배치와 저장은 아직 지원하지 않는다.
- 테스트 씬은 Build Profiles에 자동 등록하지 않는다. 이번 완료 범위는 Mac 편집기 검증까지이며 모바일 입력·빌드는 후속 작업이다.

## iPhone 모바일 조작 구현

2026-10-28, 사용자의 iPhone 실기기 선택과 모바일 조작 구현 요청에 따른 기록이다.

- D-013: iPhone을 첫 모바일 테스트 기기로 정한다. Android 대응은 후속이며 최소 iPhone·iOS 버전은 실기기 정보 확인 후 결정한다. Xcode·iOS Build Support 설치 완료는 사용자 보고다.
- D-014: 왼쪽 안전 영역 안의 고정 조이스틱과 오른쪽 드래그로 조작한다. 시작한 손가락 ID에 역할을 고정해 동시 입력·개별 해제·취소를 처리하고, Screen.safeArea와 화면 변화에 맞춰 배치를 갱신한다. 기존 Mac 조작은 유지한다.
- D-015: 기존 EnhancedTouch를 사용하고 새 패키지는 추가하지 않는다. 시제품 UI는 매 프레임 입력 처리와 분리한 IMGUI 표시로 구성한다. 정식 UI·성능 최적화는 후속이다.
- D-016: 실기기 첫 검증은 가로 화면 양방향을 기본값으로 한다. 빌드 준비 메뉴는 실행한 경우에만 로컬 씬 목록·화면 방향·실기기 SDK 설정을 변경한다. 서명·빌드는 사용자 Mac에서 진행한다.
- 런타임 생성 재질을 Resources 자산으로 참조하고, 생성하는 렌더러·충돌체를 link.xml로 보존한다. 자세한 검증은 [IPHONE](IPHONE.md)에 기록한다.

## iPhone 앱 식별자 보존

2026-10-29 (한국 시간), 사용자가 지정한 식별자와 Mac 로컬 설정·빌드 출력 검토를 근거로 기록한다.

- D-017: iPhone 시제품의 Bundle Identifier(앱 고유 식별자)는 `com.ahnmacmini.mobilemmorpg.prototype`를 사용한다. 내보낸 Xcode 프로젝트에는 이 값이 있었지만 Unity 원본 설정에는 템플릿 값이 남아 있어 `ProjectSettings/ProjectSettings.asset`의 `applicationIdentifier.iPhone`만 맞춘다. 다음 Unity 빌드에서도 지정 값이 유지되도록 하기 위한 변경이다.
- 기존 iPhone 씬 목록·가로 화면 설정·재질 변경을 보존한다. 서명 키·인증서·Xcode 빌드 출력은 GitHub 반영 대상에서 제외한다. 식별자 저장은 최소 지원 OS·유료 서비스·배포 방식의 확정을 뜻하지 않는다.
- 이번 설정과 문서는 로컬 검토용 변경이며, GitHub 반영 상태는 [STATUS](STATUS.md)에 기록한다.
